# myrs / myrsgraal

Middle backend/systems-разработчик. Пишу на Go, Rust и Python, работаю с Linux.

Разрабатываю и сопровождаю клиентские сервисы, занимаюсь сборкой и доставкой ПО.
Основные интересы — бэкенд, системная разработка и реверс-инжиниринг.
При необходимости беру задачи DevOps, фронтенда и прикладного ML/CV.

## Стек и инструменты

- **Языки:** Go, Rust, Python.
- **Среда:** Linux, Docker, Git, CI/CD.
- **Инструменты разработки:** Codex.

## Проекты

- [ton-vanity-rs](https://github.com/MYRSGRAL/ton-vanity-rs) — локальный генератор TON-адресов с выбранным окончанием на Rust и OpenCL. Поиск на CPU или GPU, проверка результатов на CPU и сохранение прогресса. Linux и Windows.
- [sshdock](https://github.com/MYRSGRAL/sshdock) — сервис на Rust для управления SSH и режимом сна ноутбука в зависимости от Wi-Fi сети и подключения питания. Интеграция с systemd и UPower.
- [tofu](https://github.com/MYRSGRAL/tofu) — проект нативного прокси-клиента для Linux на Xray-core и sing-box. В разработке; исходники пока не опубликованы.
